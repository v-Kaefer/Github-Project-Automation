# Política do Project Board (PT-BR)

## Campos gerenciados

- Phase
- Item Type
- Priority
- Status
- Test Type
- Milestone

## Status base

- backlog
- ready
- in-progress
- in-review
- done
- blocked

## Tipos de item

- user-story
- task
- bug
- repo
- stretch

As opções canônicas estão em `config/project/project-definition.json`. Labels sincronizadas com o board devem utilizar o mesmo valor em letras minúsculas após o prefixo, por exemplo `status:in-review` e `type:task`.

As views listadas na definição são recomendações e ainda precisam ser configuradas manualmente.
