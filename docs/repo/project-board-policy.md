# Project Board Policy (EN)

## Managed fields

- Phase
- Item Type
- Priority
- Status
- Test Type
- Milestone

## Status baseline

- backlog
- ready
- in-progress
- in-review
- done
- blocked

## Item types

- user-story
- task
- bug
- repo
- stretch

The canonical options are defined in `config/project/project-definition.json`. Labels that synchronize into the board must use the same lowercase values after their prefix, for example `status:in-review` and `type:task`.

Project views listed in the definition are recommendations and currently require manual configuration.
